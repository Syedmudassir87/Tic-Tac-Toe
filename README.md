Tic Tac Toe Game 🎮

## About

Tic Tac Toe is a simple and interactive game built using HTML, CSS, and JavaScript. Two players take turns marking X and O on a 3×3 grid. The first player to get three marks in a row, column, or diagonal wins the game.

## Features

- Two-player gameplay
- Interactive 3×3 game board
- Automatic winner detection
- Draw detection
- Restart game option
- Simple and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Play

1. Open the game in your browser.
2. Player X starts the game.
3. Players take turns clicking an empty box.
4. The first player to get three marks in a row, column, or diagonal wins.
5. Click the restart button to play again.

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in your browser.
